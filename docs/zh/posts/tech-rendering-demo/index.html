數學式 Link to heading

建置期就用 KaTeX 渲染完成，訪客端不需要 JavaScript，關掉 JS 也看得到。 不用在 front matter 寫 math = true。

行內用 \( \)：雜湊碰撞的生日界大約在 2n/22^{n/2}2n/2 次查詢， 所以 SHA-256 的碰撞抗性是 21282^{128}2128 而不是 22562^{256}2256。

區塊用 $$ $$：

P(碰撞)≈1−e−k(k−1)2N P(\text{碰撞}) \approx 1 - e^{-\frac{k(k-1)}{2N}} P(碰撞)≈1−e−2Nk(k−1)​

多行對齊：

c=Ek(m)⊕r =(m⋅k mod p)⊕r \begin{aligned} c &= E_k(m) \oplus r \ &= (m \cdot k \bmod p) \oplus r \end{aligned} c​=Ek​(m)⊕r ​=(m⋅kmodp)⊕r​

矩陣與大型運算子：

H=∑i=1n[aibi cidi]其中∫0∞e−x2 dx=π2 H = \sum_{i=1}^{n} \begin{bmatrix} a_i & b_i \ c_i & d_i \end{bmatrix} \quad\text{其中}\quad \int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2} H=i=1∑n​[ai​​bi​ ci​​di​​]其中∫0∞​e−x2dx=2π​​

為什麼行內不用 $ $ 開了之後「這台設備要價 $50000 到 $60000 台幣」裡的 $50000 到 $ 會被當成一條行內數學式吃掉。價格在技術文章裡太常見，所以行內一律用 \( \)。 行內程式碼與程式碼區塊裡的 $ 不受影響。

程式碼 Link to heading

一般區塊 Link to heading

import hashlib, hmac

def verify(secret: bytes, payload: bytes, signature: str) -> bool:
    """用固定時間比較，避免以時間差推回簽章。"""
    expected = hmac.new(secret, payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
