簡介 Link to heading

我是于京平（hicat0x0），目前就讀國立臺北科技大學　資訊安全碩士學位學程（MPIS）， 於 2026 年自國立臺南大學　資訊工程學系取得學士學位。

研究與實作興趣集中在資訊安全攻防、無線通訊與 SDR、雲端與虛擬化系統， 以及量子計算等前瞻題目。大學期間投入資安社群與 CTF 賽事， 從競賽與專題中累積漏洞分析、逆向工程與系統防禦的實戰經驗。

我習慣把讀到的概念轉成可以跑起來的工具或範例， 並在這個部落格記錄技術筆記、解題過程與踩坑心得。
