Mathematics Link to heading

Rendered at build time with KaTeX. No JavaScript is needed in the browser, and no math = true in front matter.

Inline maths uses \( \): the birthday bound puts a collision at roughly 2n/22^{n/2}2n/2 queries, which is why SHA-256 offers 21282^{128}2128 collision resistance rather than 22562^{256}2256.

Block maths uses $$ $$:

P(collision)≈1−e−k(k−1)2N P(\text{collision}) \approx 1 - e^{-\frac{k(k-1)}{2N}} P(collision)≈1−e−2Nk(k−1)​

Why inline maths does not use $ $ With single dollars enabled, “the rig costs $50000 to $60000” has $50000 to $ swallowed as an inline formula. Prices are common in technical writing, so inline maths always uses the parenthesis form.

What D2 cannot do Link to heading

Limits I have actually hit, recorded so I do not retry them:

ItemStatusWorkaround
Gantt chartNo such syntax; the keyword is parsed as a node nameUse Mermaid
Pie / bar chartSameUse Mermaid, or a table
MindmapSameApproximate with a tree
LaTeX blockPanics, failing the buildPut maths outside the diagram
Code block inside a shapeText overflows its shape by 13-24pxUse a Markdown block instead
Remote icon URLThe URL is written into the SVG, so readers fetch itUse a local file

Plain block Link to heading

import hashlib, hmac

def verify(secret: bytes, payload: bytes, signature: str) -> bool:
    """Constant-time comparison, so timing cannot leak the signature."""
    expected = hmac.new(secret, payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
